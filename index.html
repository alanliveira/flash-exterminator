Sobre o projeto

Flash Exterminator é um jogo espacial criado em Adobe Flash e executado no navegador pelo emulador Ruffle. Ele foi desenvolvido como projeto da disciplina Desenvolvimento de Jogos para Web I, do curso técnico em Jogos Digitais no ano de 2016.

Use as setas para movimentar a nave e a barra de espaço para atirar. Clique no jogo uma vez para ativar o áudio e dar foco aos controles.

Requisitos mínimos

  • Navegador atualizado com WebAssembly habilitado.
  • Conexão com a internet para carregar o Ruffle.
  • Executar o projeto por um servidor local, como o Live Server.
  • Teclado para controlar a nave.
